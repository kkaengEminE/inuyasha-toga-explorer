# 이누야샤 — 투아왕의 무덤 (Tōga's Grave)

《이누야샤》의 투아왕(이누노타이쇼) 무덤에서 영감을 받은 **비공식 팬 제작 Three.js 3D 탐험 프로토타입**입니다. 원작의 공식 이미지/3D 모델/음악은 포함하지 않았습니다. 형태는 코드로 직접 생성합니다.

## 실행

이 폴더에서 다음을 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>으로 접속합니다. `index.html` 파일을 직접 열어도 작동할 수 있지만, 로컬 서버를 권장합니다. Three.js를 CDN에서 불러오기 때문에 인터넷 연결이 필요합니다.

## 조작

| 키 | 기능 |
|---|---|
| `WASD` | 이동 |
| 마우스 | 시점 돌리기 (클릭해서 포인터 잠금, 실패하면 드래그로 회전) |
| `Space` | 지상에서 점프 / 비행 중 상승 |
| `Space` 빠르게 2회 | 비행 모드 켜기·끄기 |
| `Shift` | 비행 중 하강 / 지상 질주 |
| `R` | 추가 가속 |
| `V` | 1인칭/3인칭 전환 (3인칭에서 농부 캐릭터 노출) |
| `F` | 비행 모드 토글 대체키 |
| `1` / `2` / `3` | 입구 / 두개골 / 갈비뼈 구역 이동 |
| `E` | 가까운 인물·유적 설명 |
| `H` | 조작 도움말 |
| `Esc` | 포인터 잠금 해제 (이동은 계속 가능) |

## 탐험 요소

- 사후 세계의 경계, 산악 안개, 달과 영혼 입자
- 거대한 개 요괴의 두개골, 뿔 형태의 귀뼈, 아래턱, 송곳니, 갑옷 및 갈비뼈
- 공중에 떠 있는 **셋쇼마루**, **이누야샤** (기하학적 로우폴리 재구성)
- 농부 차림 플레이어: 삿갓, 삼베 옷, 짐 바구니, 호미
- 갈비뼈 내부의 철쇄아 제단

## GitHub Pages

빌드가 필요 없는 정적 HTML 프로젝트입니다. 저장소의 `main` 브랜치 루트에 `index.html`을 올리고 **Settings → Pages → Deploy from a branch → main → /(root)**로 설정하면 됩니다.

현재 GitHub 저장소 `kkaengEminE/inuyasha-toga-explorer`에서 GitHub Pages 배포를 진행합니다. `main` 브랜치 루트를 배포하도록 설정하면 이후 코드 업데이트가 자동 반영됩니다.
